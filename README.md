# SentAI

SentAI is an AI-powered email management and drafting assistant designed to streamline your email workflow. Built with modern web technologies, it integrates leading AI models to help you compose, refine, and manage your emails efficiently.

## Features

- **AI-Powered Drafting:** Utilize advanced LLMs to draft emails based on your intent.
- **Email Management:** Intuitive interface for organizing and handling email threads.
- **Customizable Settings:** Personalize your AI assistant's behavior.
- **Modern Tech Stack:** Built for performance and reliability using React, Vite, and TypeScript.

## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Build Tool:** Vite
- **AI Services:** OpenAI, Anthropic, Google Gemini

## Getting Started

### Prerequisites

- [pnpm](https://pnpm.io/)

### Installation

```bash
pnpm install
```

### Running the App

```bash
pnpm dev
```

The application will be available at `http://localhost:3000`.

### Building for Production

```bash
pnpm build
```
